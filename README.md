🤖 Simple Rule-Based Chatbot (HTML, CSS & JavaScript)

> A beginner-friendly chatbot developed using **HTML**, **CSS**, and **JavaScript**. The chatbot responds to predefined user questions using simple JavaScript logic and demonstrates the fundamentals of DOM manipulation and event handling.

📖 Overview

This project is a simple web-based chatbot created as part of my web development learning journey.

Instead of using Artificial Intelligence or external APIs, the chatbot uses predefined questions and answers stored in a JavaScript object. When a user's input matches one of the stored questions, the chatbot returns the corresponding response. Otherwise, it displays a default message indicating that the input was not recognized.

This project helped me understand how chat interfaces work before learning more advanced chatbot technologies.

💡 Sample Questions

The chatbot can answer predefined questions such as:

- Hi
- Who are you?
- How are you?
- How old are you?
- What school are you from?
- Bye

If an unrecognized question is entered, the chatbot will respond with a default message.
